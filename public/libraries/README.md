# Excalidraw public library

`architecture.excalidrawlib` is the unmodified “Architecture floor plan symbols” library by [Arqtangeles](https://github.com/Arqtangeles), obtained from the [official Excalidraw Libraries repository](https://github.com/excalidraw/excalidraw-libraries/blob/main/libraries/Arqtangeles/architecture.excalidrawlib).

42 editable 2D floor-plan symbols. Original catalog date: 2021-05-14. Retrieved: 2026-09-12. License: MIT; see LICENSE-excalidraw-libraries.txt. This is a 2D drawing library, not a collection of 3D models. Imported shapes become part of the project's saved scene when placed on the canvas.
