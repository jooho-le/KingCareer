# KingCareerLLM — 서비스 그래픽 에셋 v1

## 구성
총 **113개 에셋**, PNG 113개, SVG 90개입니다. 같은 에셋의 PNG와 SVG는 별도 에셋으로 중복 계산하지 않았습니다.

- `00_brand`: 브랜드 로고 3개
- `01_mascots`: 킹크랩 캐릭터 9개
- `02_expressions`: 표정 아바타 8개
- `03_icons`: 기능 아이콘 28개
- `04_feature_illustrations`: 핵심 기능 일러스트 6개
- `05_career_illustrations`: 직업별 벡터 일러스트 5개
- `06_generated_card_art`: 직업별 생성 썸네일 5개
- `07_status`: 상태 그래픽 6개
- `08_badges`: 경험 배지 6개
- `09_ui_components`: UI 컴포넌트 18개
- `10_decorations`: 연결선·장식 10개
- `11_backgrounds`: 독립 배경 9개

## 먼저 볼 파일
`index.html`은 전체 PNG가 내장된 독립 미리보기입니다. 인터넷 연결 없이 열 수 있습니다.
`manifest.json`에는 개별 에셋의 용도, 원본/출력 크기, 제작 방식과 사용 제한이 있습니다.

## 캐릭터 원본과 작은 변형의 구분
- `01_mascots/mascot_00_original.png`: 마지막으로 확정한 1254×1254 캐릭터입니다. 주황색 몸, 금색 왕관, 파란 후드티, 흰색 KingCareerLLM 글씨를 유지했습니다. 배경의 고립된 미세 픽셀만 제거했습니다.
- 나머지 8개 포즈와 표정 아바타는 새 생성 작업 시트에서 분리한 **소형 래스터 컴포넌트**입니다. 작은 옷 로고는 원본 생성의 세부 한계가 남아 있으므로 큰 히어로 용도로 확대하지 마세요. 로고를 선명하게 보여야 하는 화면에는 확정 원본을 사용하세요.
- 생성 썸네일 5개 역시 작은 카드용 원본 크기를 유지했습니다. 파일의 픽셀 수를 늘려 고해상도라고 표시하지 않았습니다.

## 벡터·배경
- 브랜드 로고, 아이콘, 기능/직업 일러스트, 상태, 배지, UI, 장식, 배경에는 SVG 원본과 PNG가 함께 있습니다.
- 배경 9개는 모두 1920×1080이며, 캐릭터·본문 문구가 들어 있지 않습니다. 주된 텍스트·선택지는 빈 영역에 별도로 배치합니다.
- 개발자, 간호사, 스마트팜, 자동차, 식품 연구원 시뮬레이션 공간 5종을 포함합니다. 실제 기업·장소나 실제 실험 절차를 재현한 자료가 아닙니다.
- 지역 일러스트는 한옥·도시·강을 이용한 추상 모티프이며 실제 지도 자료가 아닙니다.

캐릭터의 금색 왕관은 기존 정체성을 유지하기 위해 그대로 사용했습니다.

## 구현 참고
UI 컴포넌트 PNG는 시안·발표·화면 합성용입니다. 실제 서비스에서는 버튼, 입력창, 단계 표시를 HTML/CSS로 구현하고 접근성 이름·포커스·키보드 조작을 별도로 적용해야 합니다.
SVG의 한글은 시스템 글꼴을 참조합니다. 글꼴 파일은 포함하지 않았습니다. 문구의 모양을 고정해야 하는 곳에는 PNG를 사용하세요.
활동 진행 예시 `2 / 5`를 제외하고, 능력 점수·검증되지 않은 성장률·이용자 수를 넣지 않았습니다.
