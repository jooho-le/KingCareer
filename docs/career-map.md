# 진로경험지도 화면 개편

KingCareer의 크랩·직무체험·수료 카드·포트폴리오 흐름에 맞춰 경험지도를 구성했습니다.

- 직업별 크랩 선택 카드에서 다섯 직업의 지도를 전환합니다.
- 직업 만나기, 현장 체험, 결과물 만들기를 세 가지 경험 방식으로 표시합니다. 활동 순서는 강제하지 않습니다.
- 직업 소개 기록, 완료된 체험, 제출된 프로젝트가 있을 때만 해당 체크포인트를 표시합니다. 0/3~3/3은 경험 방식의 개수이며 역량 점수가 아닙니다.
- 다음 추천 활동은 기존 서버 추천과 이유를 그대로 사용합니다.
- 수료 기록과 획득 배지는 해당 직업의 저장된 활동에서 가져옵니다. 획득하지 않은 배지 예시는 ‘아직 받기 전’으로 구분합니다.
- 최근 활동의 회고와 제출한 결과물 수를 보여줍니다.
- 여섯 항목의 기록 충족률, 누락된 목표, 활동 전후 변화와 개별 근거는 접힌 상세 영역에서 확인합니다. 근거는 종류별 필터와 더 보기로 탐색합니다.
- 전공 조사·현직자 교류의 미지원 상태와 자기보고 구분을 유지합니다.

구현: [ExperienceMap.tsx](../src/pages/ExperienceMap.tsx), [화면 스타일](../src/pages/experience-map.css).
제공된 `public/brand/12_career_kingcrabs` 원본 PNG를 사용합니다. API·점수 계산·학생 기록은 변경하지 않았습니다.

## 사용자 확인

테스트 작성·실행은 요청에 따라 하지 않습니다. 타입 검사와 프론트 빌드를 수행합니다.

1. 처음 가입한 학생, 체험 진행 중인 학생, 수료·프로젝트 기록이 있는 학생의 표시 구분.
2. 직업을 바꿀 때 체크포인트·추천·배지·회고가 해당 직업으로 바뀌는지.
3. 다음 활동·수료 카드·결과물 링크, 상세 기록 펼치기와 필터·더 보기.
4. 기록 로딩 실패 시 미완료로 오인하지 않고 다시 불러올 수 있는지.
5. 모바일의 직업 카드 가로 이동과 세로 체크포인트, 키보드 포커스, 움직임 줄이기.

기존 경험지도 화면 테스트에서 기본 노출을 기대했던 충족률과 근거 목록은 상세 영역을 펼친 뒤 확인해야 합니다.
