# 3D 현장 품질 개선

## 적용 범위

다섯 현장에 공통 환경 반사 조명, 둥근 모서리, 향상된 재질과 화질 선택을 적용했습니다. 기존 서버의 객관식 선택·경험 기록 규칙은 그대로 사용합니다.

| 구성 | 구현 |
| --- | --- |
| 표면·형태 | `RoundedBoxGeometry`, 물리 기반 재질, 금속·표면 코팅, 부드러운 원통·식물 곡면 |
| 빛 | Three.js RoomEnvironment로 로컬 환경 반사 생성, 따뜻한 주광과 차가운 보조광, 접지 그림자 |
| 높음 | 최대 DPR 2, 2048 그림자맵, 256 환경 반사맵 |
| 가벼움 | 최대 DPR 1.25, 1024 그림자맵, 128 환경 반사맵 |
| 카메라 | 대상 선택 시 부드러운 접근, 전체 보기, 직접 드래그 시 자동 접근 취소 |
| 움직임 줄이기 | 카메라는 즉시 이동하고 차량·카트는 최종 상태로 표시 |
| 자동차 | Kenney 차량·휠·콘, 리프트와 점검 표시, 조치 시 차량 상승과 장비 등장 |
| 다른 현장 | 서로 다른 배치, 키보드·마우스·의자·화분·수납장, 침대 난간·커튼, 시료 용기, 현장 표지 |
| 상태 표시 | 캔버스로 만든 현장 표지와 모니터에 서버의 실패율·온도 등 표시 |

화질은 현재 화면에서 선택합니다. 새로 들어오면 높음으로 시작합니다. 전체 보기는 조사 선택만 해제하며 저장된 조사·조치는 취소하지 않습니다. 장면은 GLB 로딩 후 표시하며, WebGL이나 모델 로딩 오류 시 2D 조사 목록으로 체험할 수 있습니다.

모든 모델은 로컬 `public/models/kenney`에서 읽으며, 외부 CDN이나 API를 호출하지 않습니다. 데이터 파일과 장비 모델은 구분되어 있어 시뮬레이션 결과를 다시 계산하지 않고 저장된 상태를 재현합니다.

## 사용자 확인 항목

요청에 따라 테스트를 작성하거나 실행하지 않습니다. 타입 검사와 빌드만 수행합니다.

1. 다섯 직업의 GLB·표지·재질이 표시되는지, 확대 시 장비와 글자가 읽히는지.
2. 자동차 조치 뒤 리프트와 점검 장비, 개발자 실패율, 온실 온도가 저장 결과와 일치하는지.
3. 대상 선택·전체 보기·드래그 취소·모바일 확대, 움직임 줄이기 동작.
4. 화질 선택 시 선명도와 프레임 속도, 작은 화면에서 도구 모음 배치.
5. 페이지를 반복 이동할 때 모델 재사용과 WebGL 자원 해제, 2D 목록 전환.

실사 렌더링, 광선 추적, 물리 엔진에 의한 정비·임상 시뮬레이션은 구현하지 않았습니다. 이번 장면은 교육용 미니어처 3D입니다.
