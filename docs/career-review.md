# 경험을 다음 선택으로 연결하는 UPDATE

포트폴리오의 **크랩과 경험 돌아보기**에서 완료한 직무체험·프로젝트를 선택합니다. 재미있었던 일, 어려웠던 점, 다시 해보고 싶은지를 객관식으로 답하고 경험 정리를 요청합니다. 발견한 나·근거 활동·기록이 없는 목표·다음 활동을 읽은 뒤 ‘비슷해요 / 조금 달라요’를 선택합니다. 수정도 객관식으로 가능하며 메모는 선택입니다. 학생이 확인한 내용과 직접 고른 다음 활동은 직업 지도와 텍스트 포트폴리오에 표시합니다.

## AI와 계산

`KINGCAREER_AI_MODE=ai`는 기존 `backend/.env`의 Gemini 또는 OpenAI 호환 제공자 설정으로 `reflect()`를 호출합니다. 선택한 활동과 최근 최대 6개 활동의 제한된 답변·회고·관심도·선택 로그, 이번 객관식 응답, Gap Engine의 빈 목표와 후보를 전달합니다. 계정·학교·지역·사용자 ID나 설계 이미지 파일은 보내지 않습니다. 학생이 본문에 적은 정보는 본문에 포함될 수 있으며 요청 버튼 앞에 전달 범위를 표시합니다.

AI 응답의 근거 참조와 다음 활동 ID를 서버 목록과 대조합니다. AI 문장의 의미 전체를 자동 검증하는 기능은 아니므로 학생이 읽고 수정·확인합니다. `template` 모드는 **기록 기반 정리 · AI 미사용**으로 표시하며, AI 호출 실패를 템플릿 성공으로 바꾸지 않습니다.

회고는 적성·역량 점수를 만들지 않습니다. 확인 시 xAPI 기록은 `self_report`, `objectives=[]`으로 저장하므로 경험 충족률을 올리지 않습니다. 전공 조사·현직자 교류처럼 아직 확인할 수 없는 목표는 기록 없음으로 남깁니다.

## API와 저장

| API | 내용 |
| --- | --- |
| `GET /api/v1/career-reviews` | 본인 회고 목록, 선택지, 생성 모드 |
| `PUT /api/v1/career-reviews/{activityId}/answers` | 세 응답과 expectedVersion·clientRequestId 저장 |
| `POST /api/v1/career-reviews/{activityId}/generate` | 저장한 응답과 실제 기록으로 정리 생성 |
| `PUT /api/v1/career-reviews/{activityId}/confirm` | 확인·수정·선택 메모·다음 활동 저장 |

`004_career_reviews.sql`은 서버 시작 시 자동 적용됩니다. 활동별 최신 회고 하나를 저장하며, AI 원문과 학생 확인 내용을 구분합니다. 전체 수정 이력을 보관하지는 않습니다. 응답을 다시 작성하면 확인 대기로 돌아갑니다. 활동·계정 삭제 시 외래키로 함께 삭제됩니다.

요청 재전송과 버전 충돌을 처리하며, 동일한 확인 내용을 재저장해도 xAPI 기록을 추가하지 않습니다. 생성 동안 SQLite 쓰기 잠금을 유지하지 않습니다. 생성 실패 시 객관식 응답을 보관합니다. 새로고침하면 생성 상태를 다시 조회하고 75초 이상 중단된 요청은 재시도 가능한 상태로 되돌립니다. 생성 중 응답이 변경되거나 활동이 삭제되면 이전 결과를 반영하지 않습니다.

## 사용자 확인 항목

- 완료 기록이 없는 계정, 체험·프로젝트 완료 후 회고 진입.
- 세 응답 저장, 생성 실패 후 재시도, 새로고침 후 복원.
- AI/기록 기반 표시, 근거 활동, ‘조금 달라요’와 선택 메모 반영.
- 확인 전 지도 미표시, 확인 후 다음 활동 연결·다운로드 포함.
- 계정 간 접근 차단, 활동·계정 삭제 시 회고 삭제, 중복 확인 시 점수 불변.
- 두 창에서 수정할 때 버전 충돌 안내와 입력 유지.

현재 브라우저 회귀 검사는 활동 ID 유지, 기존 회고 답 재사용·수정, AI 자동 호출 없음, 다음 활동 우선순위를 확인합니다. 실제 Gemini 응답 품질은 검사하지 않았습니다. 실행 결과는 [검증 기록](ui-validation.md)을 참고합니다.


## 화면 위치

회고는 /app/#review, 확인한 회고와 경험 현황은 프로필 → 나의 진로 기록, 선택한 다음 활동은 홈에서 확인합니다. 포트폴리오는 결과물과 수료 카드를 중심으로 구성합니다.
