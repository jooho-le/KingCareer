# 잇다 프론트엔드 IA

## 화면과 경로

| 경로 | 화면 | 주요 동작 |
| --- | --- | --- |
| `#home` | 홈 | 실제 저장한 활동 수, 다음 직업, 진단·체험·프로젝트 진입 |
| `#onboarding` | 온보딩 | 소개, 사용자 유형, 복수 관심분야·미정 선택 |
| `#auth` | 프로필 시작 | 로컬 프로필 작성·재진입, 계정 복구 범위 안내 |
| `#diagnosis` | 관심·경험 진단 | 직업 선택, 6개 질문, 결과 저장 |
| `#map` | 진로경험 지도 | 직업 전환, 레이더·영역별 지표, 최근 전후 변화, 기록 |
| `#simulation` | AI 직무체험 | 직업 탐색, 역할 안내, 3개 상황, 선택·자유 답변, 회고, 결과 |
| `#projects` | 미니 프로젝트 | 추천 목록, 주제·목표·미션, 초안 작성, 힌트, 제출 |
| `#discovery` | 직업 발견 | 분야·키워드·저장 필터, 직업 상세, 전공·연관 직업, 체험 |
| `#region` | 전북 지역 탐색 | 전주·군산·익산·김제·완주·새만금, 산업 예시, 가상 기관 |
| `#recommendation` | 다음 경험 | 관심과 경험 공백 확인, 추천 이유, 체험·프로젝트 연결 |
| `#portfolio` | 포트폴리오 | 종류별 활동 필터, 상세 결과물·피드백, 성장, 다운로드·복사 |
| `#teacher` | 교사·멘토 | 가상 학생 목록·지도, 공백 필터, 로컬 배정, 가상 리포트 |
| `#profile` | 마이페이지 | 프로필·관심, 저장 직업, 알림 설정, 데이터 삭제 |

체험과 프로젝트는 `?career=developer`, `nurse`, `farmer`, `engineer`, `researcher`를 붙여 해당 직업의 안내 화면으로 바로 진입할 수 있습니다. Hash 경로를 사용해 정적 호스팅에서도 새로고침과 브라우저 뒤로 가기를 지원합니다.

## 경험 데이터

진단의 6개 영역은 직업 인식, 직무 이해, 활동 경험, 역량 이해, 학과 이해, 현직자 교류입니다. 자가 응답을 10·45·75의 출발점 지표로 표시합니다. 미진단 영역의 0은 미확인을 뜻합니다.

직무체험 완료 시 앞의 4개 영역에 각각 최소 60·60·40·50, 프로젝트 완료 시 최소 65·65·65·60의 완료 기준을 반영합니다. 기존 값이 더 높으면 유지합니다. 관련 학과와 현직자 교류는 해당 체험으로 바뀌지 않습니다. 모든 값은 기획 검증용 기준이며 평가 모델의 추정값이 아닙니다.

활동에 답변, 회고, 당시 관심도, 피드백, 활동 전후 지표를 함께 저장합니다. 관심도는 1–5로 학생이 직접 선택하며 감소해도 완료로 기록합니다. 활동 완료 전에는 지표를 갱신하지 않습니다.

## 인터랙션과 접근성

페이지는 짧은 페이드·슬라이드로 전환하고, 메뉴 선택 표시가 다음 위치로 이동합니다. 직업 카드는 hover 반응, 버튼은 클릭 반응, 진행 막대와 진로지도는 등장 애니메이션을 사용합니다. 장식 그래픽은 천천히 움직입니다.

`prefers-reduced-motion`을 켜면 CSS 장식 애니메이션과 전환을 끄고 Motion의 움직임 줄이기 설정을 적용합니다. 입력 레이블, 키보드 포커스, 모달 포커스 제한·Escape 닫기, 진행 지표, 본문 건너뛰기를 제공합니다.

## 서버 연결 전 남은 범위

- 인증, 사용자별 권한, 교사·학생 연결과 계정 복구
- 동의·보관 정책을 적용한 서버 데이터 저장과 기기 간 동기화
- 생성형 AI 기반 상황 분기·자유 답변 분석·피드백
- 검증된 경험지표와 추천 모델, 콘텐츠 사실성 검토
- 실제 기업·대학·현직자 및 지역 프로그램 데이터
- 공유 링크·PDF 생성, 실제 알림 발송

현재 교사 화면과 가상 기관은 화면 흐름을 확인하기 위한 예시입니다. 실제 학생이나 기관에 연락하거나 데이터를 전송하지 않습니다.
