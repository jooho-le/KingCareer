# KingCareer 학생 화면 IA

공개 소개 페이지 `/`와 학생 앱 `/app/`는 별도 HTML 문서입니다. 학생 앱은 해시 경로를 사용합니다. 기존 `/#home`, `/#diagnosis` 같은 알려진 학생 앱 링크는 `/app/`로 이동합니다.

## 화면과 경로

로컬 확장: `/app/#simulation?career=<id>`에서 다섯 직업별 3D 현장·2D 조사 목록 → 자료 비교 → 조치 → 재확인 → 인계 → 회고 → 수료 카드로 이동합니다. `/app/#projects?career=<id>`는 직업별 Excalidraw 설계도·세 설명 → 초안·수정 이력 → 제출·코치 피드백 → 포트폴리오입니다. 포트폴리오에 배지 컬렉션·수료 카드 선택·제출 당시 배치도 보기를 추가했습니다. [로컬 범위](local-fieldwork.md)를 참고합니다.

| 화면 | 경로 | 주요 구성·연결 |
| --- | --- | --- |
| 소개 | `/` | 원본 3D 큐브·스크롤 소개, 직업 트랙, 공개 체험 예시, 경험지도 예시, 직무 현장 목록, 앱 시작 |
| 온보딩 | `/app/#onboarding` | 학생 대상 안내, 첫 관심분야 선택, 계정 시작 |
| 로그인·가입 | `/app/#auth` | 아이디·비밀번호·닉네임으로 학생 계정 시작 |
| 홈 | `/app/#home` | 나의 최근 활동, 다음 경험, 다섯 직무 현장, 수료증·배지 연결 |
| 관심·경험 진단 | `/app/#diagnosis` | 직업 선택, 6개 자기보고 응답, 결과 기록, 지도·체험 연결 |
| 경험지도 | `/app/#map` | 직업별 기록 충족률, 근거·미확인 영역, 활동 전후 변화 |
| 직무체험 | `/app/#simulation` | 직업 목록, 3D 현장 조사, 객관식 조치·확인·인계·회고, 선택적 코치 질문, 수료 카드 |
| 미니 프로젝트 | `/app/#projects` | 직업별 과제, 3단계 미션, 작성 가이드, 초안·수정 이력, 제출 |
| 직업 발견 | `/app/#discovery` | 분야·검색, 업무·역량·전공, 관련 직업, 관심 저장, 체험 연결 |
| 다음 경험 | `/app/#recommendation` | 부족한 목표, 다음 활동, 추천 이유와 그래프 경로 |
| 포트폴리오 | `/app/#portfolio` | 활동별 답변·결과물·회고, 변화 기록, 텍스트 다운로드 |
| 마이페이지 | `/app/#profile` | 프로필·관심분야·저장 직업, 알림 환경설정, 비밀번호·기록·계정 관리 |

직업을 지정할 때는 `?career=developer`를 붙입니다. 가능한 ID는 `developer`, `nurse`, `farmer`, `engineer`, `researcher`입니다. 예: `/app/#simulation?career=farmer`, `/app/#projects?career=developer`.

## 로그인과 기록

- 소개, 직업 탐색과 체험·프로젝트 목록은 공개 화면입니다. 개인 진단·지도·추천·포트폴리오·프로필, 활동 시작과 직업 저장에는 로그인이 필요합니다.
- 활동 도중 로그인으로 이동하면 로그인 후 해당 활동·직업으로 돌아갑니다. 학생 계정만 지원하며 사용자 유형·교사·멘토·가상 학생·배정 메뉴는 없습니다.
- 학교·학년·지역은 가입 후 마이페이지에서 선택적으로 입력합니다. 온보딩에서 고른 관심분야는 가입할 때 함께 저장합니다.
- 공개 소개 페이지의 체험과 수치는 예시입니다. 이 페이지에서 선택한 내용은 학생 계정이나 포트폴리오에 반영하지 않습니다.
- 진단은 자기보고로 저장합니다. 체험·제출물의 실제 저장 여부와 구분하며 화면에서 점수를 계산하거나 고정값을 더하지 않습니다.

## 활동 화면의 상태

직무체험은 서버에서 `brief`, `play`, `reflection`, `completed` 단계를 결정합니다. 선택 결과를 확인한 다음 다음 상황으로 이동합니다. 질문은 현재 단계에 머물며 서버에 기록합니다. 자유 답변은 템플릿 모드에서 내용 평가를 하지 않습니다. 같은 직업으로 다시 들어가면 진행 중 세션부터 이어하고, 완료 후 다시 시작하면 새로운 세션을 만듭니다.

프로젝트는 입력을 잠시 멈추면 초안을 자동 저장합니다. 저장 대기·저장 중·저장 완료·실패를 구분합니다. 미저장 내용이 있으면 페이지 이동 전에 저장하고, 실패하면 현재 화면과 입력을 유지합니다. 다른 창에서 수정한 경우 최신 버전을 확인하고 현재 입력으로 저장할지 선택합니다. 브라우저 닫기·새로고침에는 미저장 경고를 표시합니다.

아직 제출하지 않은 시뮬레이션 자유 답변·질문·회고는 현재 화면의 입력입니다. 서버에서 저장 성공을 확인한 기록부터 재접속 시 복원됩니다.

페이지·카드 움직임은 앱의 단색 브랜드 디자인을 사용합니다. 모바일 메뉴, 키보드 조작과 움직임 줄이기를 지원합니다. 제공 이미지의 보존 범위는 [소개 페이지와 이미지 출처](landing-source.md)에 있습니다.
