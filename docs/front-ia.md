# KingCareer 학생 화면 IA

공개 소개 페이지 `/`와 학생 앱 `/app/`는 별도 HTML 문서입니다. 학생 앱은 해시 경로를 사용합니다. 기존 `/#home`, `/#diagnosis` 같은 알려진 학생 앱 링크는 `/app/`로 이동합니다.

## 화면과 경로

주 메뉴는 **홈 / 직무체험 / 미니 프로젝트 / 포트폴리오** 네 가지입니다. 프로필·진로 기록·설정은 계정 영역에서 엽니다. 직업 탐색은 직무체험 목록의 검색·관심 분야·저장 필터로 합쳤습니다. 진단과 다음 경험 추천은 독립 메뉴 대신 홈과 활동의 문맥에서 연결하며 기존 URL은 유지합니다.

첫 이용자는 홈 → 직업 목록 → 선택한 직업의 활동 안내 → 필요할 때 로그인·가입 → 현장 체험 → 수료 카드 → 경험 돌아보기로 이어갑니다. 미니 프로젝트는 선택적인 후속 활동이며 주 메뉴에서도 직접 열 수 있습니다.

로컬 확장: `/app/#simulation?career=<id>`에서 다섯 직업별 3D 현장·2D 조사 목록 → 자료 비교 → 조치 → 재확인 → 인계 → 회고 → 수료 카드로 이동합니다. `/app/#projects?career=<id>`는 Excalidraw 그림 속 가이드·빈칸 편집과 세 설명 → 초안·수정 이력 → 제출·코치 피드백 → 포트폴리오입니다. 포트폴리오에 배지 컬렉션·수료 카드 선택·제출 당시 배치도 보기를 추가했습니다. [로컬 범위](local-fieldwork.md)를 참고합니다.

| 화면 | 경로 | 주요 구성·연결 |
| --- | --- | --- |
| 소개 | `/` | 원본 3D 큐브·스크롤 소개, 직업 트랙, 공개 체험 예시, 경험지도 예시, 직무 현장 목록, 앱 시작 |
| 온보딩 | `/app/#onboarding` | 학생 대상 안내, 첫 관심분야 선택, 계정 시작 |
| 로그인·가입 | `/app/#auth` | 아이디·비밀번호·닉네임으로 학생 계정 시작 |
| 홈 | `/app/#home` | 이어하기·내가 고른 다음 경험·추천 중 주 행동 하나, 최근 완성한 결과 두 건, 접어서 보이는 직업 미리보기, 선택이 어려울 때 진단 연결 |
| 관심·경험 진단 | `/app/#diagnosis` | 홈의 ‘해본 경험부터 확인하기’에서 연결, 직업 선택, 6개 자기보고 응답, 진로 기록·체험 연결 |
| 나의 진로 기록 (프로필 탭) | `/app/#profile?tab=records` | 해본 직업·완료 상태·최근 날짜, 최근 확인한 회고 한 건 |
| 경험 돌아보기 | `/app/#review` | 객관식 회고·AI 정리 확인·다음 활동 선택 |
| 직무체험 | `/app/#simulation` | 직업·역량·전공 검색, 관심 분야·저장 필터, 펼쳐 보는 업무·전공 설명, 선택한 직업의 현장·조치·확인·인계·회고·수료 카드 |
| 미니 프로젝트 | `/app/#projects` | 다섯 직업의 손그림 흐름도·그림 속 메모 편집, 같은 구도의 완성 예시, 설명·초안·수정 이력·제출 |
| 직업 정보 상세 (기존 경로 유지) | `/app/#discovery` | 목록에서 ‘관련 직업과 정보 출처 보기’로 연결, 관련 직업·자료 출처·탐색 기록 저장, 기존 검색 링크 호환 |
| 다음 경험 (기존 경로 유지) | `/app/#recommendation` | 부족한 목표, 다음 활동, 추천 이유와 그래프 경로; 주 메뉴에는 표시하지 않음 |
| 포트폴리오 | `/app/#portfolio` | 프로젝트 결과물·수료 카드와 배지·체험 기록, 다운로드 |
| 마이페이지 | `/app/#profile` | 프로필·관심분야·저장 직업, 알림 환경설정, 비밀번호·기록·계정 관리 |

직업을 지정할 때는 `?career=developer`를 붙입니다. 가능한 ID는 `developer`, `nurse`, `farmer`, `engineer`, `researcher`입니다. 예: `/app/#simulation?career=farmer`, `/app/#projects?career=developer`.

## 로그인과 기록

- 소개, 직업 탐색과 체험·프로젝트 목록은 공개 화면입니다. 개인 진단·지도·추천·포트폴리오·프로필, 활동 시작과 직업 저장에는 로그인이 필요합니다.
- 활동 도중 로그인으로 이동하면 로그인 후 해당 활동·직업으로 돌아갑니다. 학생 계정만 지원하며 사용자 유형·교사·멘토·가상 학생·배정 메뉴는 없습니다.
- 학교·학년·지역은 가입 후 마이페이지에서 선택적으로 입력합니다. 온보딩에서 고른 관심분야는 가입할 때 함께 저장합니다.
- 공개 소개 페이지의 체험과 수치는 예시입니다. 이 페이지에서 선택한 내용은 학생 계정이나 포트폴리오에 반영하지 않습니다.
- 진단은 자기보고로 저장합니다. 체험·제출물의 실제 저장 여부와 구분하며 화면에서 점수를 계산하거나 고정값을 더하지 않습니다.

## 활동 화면의 상태

새 프로젝트는 모두 손그림 흐름도로 시작합니다. 네모·가지선·메모를 직접 수정하고 같은 구도의 완성 예시를 참고합니다. 손글씨·선·채움색을 제출물에도 그대로 보존합니다. 이전에 저장한 개발자 대화형 복구 화면은 호환 화면으로 이어할 수 있고, 파일 메뉴의 ‘기존 초안 보관하고 새 손그림 시작’으로 수정 이력을 보존한 채 전환합니다. 신규 프로젝트에는 대화형 화면을 기본으로 넣지 않습니다.

로그인 후 프로젝트 작업실은 다른 페이지와 동일한 공통 사이드바·검색·프로필 상단 바 안에 표시합니다. 별도 축소 메뉴나 전체화면 포털은 사용하지 않습니다. 남은 화면 높이에 캔버스와 `과제 / 내 설명 / 크랩 도움` 패널을 배치합니다. 작업 도구 줄에서 저장 상태를 확인하고 저장·제출·목록 이동을 합니다. 캔버스 휠 동작은 페이지 스크롤로 전달하지 않으며, 긴 설명은 패널 내부에서만 스크롤합니다. 탭을 바꿔도 입력과 코치 응답을 유지합니다. 모바일 메뉴는 다른 페이지와 같은 상단 버튼으로 열고 작업 패널은 하단 탭으로 열고 접습니다. 수정 이력·작업 백업·관심도는 과제 탭에 있습니다. 결과 화면과 목록으로 나가면 원래 페이지 스크롤을 복원합니다.

작업실 확인 범위: 캔버스 휠·드래그와 페이지 고정, 패널 스크롤, 탭 전환 후 입력·코치 답변 유지, 모바일 패널 접기, 저장 실패·백업·제출 후 복귀, 화면 안내와 키보드 접근. 실행 결과와 실제 API/테스트 응답의 구분, 임시 프로젝트의 실제 Gemini 연결 확인은 [검증 기록](ui-validation.md)을 참고합니다.

화면 안내는 배경을 어둡게 하는 오버레이와 실제 영역 강조·화살표로 표시합니다. 다음·이전으로 영역을 살펴보고 닫기·Escape로 끝냅니다. 안내 중에는 배경 조작을 막습니다. 설정에서 다시 보기를 누르면 실제 활동 페이지로 이동합니다. 미니 프로젝트에는 작성 항목과 질문을 버튼으로 고르는 크랩 코치가 있으며, 초안 저장 후 힌트를 요청합니다. AI 미연결 시 기본 안내로 구분합니다.

직무체험과 미니 프로젝트의 목록·활동 안내·작업 화면은 계정별로 처음 볼 때 한 번 자동 안내합니다. 작업실 안내는 과제 → 작성 방식 → 설명 → 제출 순서이며 실제 패널을 열고 닫으면 원래 패널로 돌아갑니다. 본 기록과 ‘다시 보지 않기’는 이 브라우저의 localStorage에 저장하며 게스트와 계정을 분리합니다. 서버나 다른 브라우저에 동기화하지 않습니다. ‘다시 보지 않기’를 해제해도 이미 본 화면은 반복하지 않습니다. 활동 상단 ‘화면 안내’ 또는 프로필 → 설정 → 활동 도움말에서 언제든 다시 열 수 있습니다. 저장 실패는 도움말 안에 표시합니다.

관심도 초안 복원, 정확한 활동 회고, 그림 썸네일과 결과물 문서, 홈의 다음 활동 우선순위는 [리뷰 후 개선](review-improvements.md)에 정리했습니다. 메뉴 간소화·최초 방문 도움말·모바일 할 일 → 자료 → 선택 → 결과 순서와 그림 속 가이드는 [학생 사용 흐름 개선](student-usability.md)을 참고합니다.

완료 후 별도 회고 화면에서 활동 선택 → 객관식 회고 → AI 또는 기록 기반 정리 → 학생 확인·수정 → 다음 활동 선택으로 이어집니다. 확인한 회고는 프로필의 나의 진로 기록에, 선택한 다음 활동은 홈에 표시합니다. [UPDATE 단계와 API](career-review.md)를 참고합니다.

직무체험은 서버에서 `brief`, `play`, `reflection`, `completed` 단계를 결정합니다. 선택 결과를 확인한 다음 다음 상황으로 이동합니다. 질문은 현재 단계에 머물며 서버에 기록합니다. 자유 답변은 템플릿 모드에서 내용 평가를 하지 않습니다. 같은 직업으로 다시 들어가면 진행 중 세션부터 이어하고, 완료 후 다시 시작하면 새로운 세션을 만듭니다.

직무체험은 근무 장소 미리보기와 동료 크랩의 업무 안내 → 물건 조사 → 원인 판단 → 조치·결과 → 인계·회고로 진행합니다. 조사 중에는 현장을 크게 보여주고 선택지를 숨깁니다. 물건을 누르면 서버 저장을 확인한 조사 카드가 열리며, 넓은 화면에서는 현장 위에, 좁은 화면에서는 자료 목록 아래에 표시합니다. 자료 목록과 화면 설정은 접어 두며 2D 목록으로 모든 조사를 할 수 있습니다. 필수 자료를 포함한 세 곳 이상을 조사하고 ‘원인 선택으로 이동’을 누르면 선택지가 열립니다. 이때 현장은 접지 않습니다. 넓은 화면에서는 현장 옆에 선택지를 놓고, 좁은 화면에서는 아래에 놓습니다. 패널 내부의 별도 스크롤은 없으며 3D 휠 입력만 페이지에 전달되지 않습니다. 단계 목록과 작업일지는 접어 둡니다. 조치 결과는 다음 선택 바로 앞에서 한 번 보여줍니다. 회고에서는 관심도를 1~5 버튼으로 고르고, 좋았던 점·어려웠던 점은 선택 항목을 펼쳐 남깁니다. 동료 크랩의 안내는 작성된 시나리오 설명이며 AI 생성 응답으로 표시하지 않습니다.

프로젝트는 입력을 잠시 멈추면 초안을 자동 저장합니다. 저장 대기·저장 중·저장 완료·실패를 구분합니다. 미저장 내용이 있으면 페이지 이동 전에 저장하고, 실패하면 현재 화면과 입력을 유지합니다. 다른 창에서 수정한 경우 최신 버전을 확인하고 현재 입력으로 저장할지 선택합니다. 브라우저 닫기·새로고침에는 미저장 경고를 표시합니다.

프로젝트는 Excalidraw 손그림 편집기로 열립니다. 빈 캔버스에는 ‘손그림 흐름도 넣기’, 그림이 있으면 ‘그림 전체 보기’를 표시해 도안이 반복 추가되지 않도록 했습니다. 네모와 안의 글, 화살표는 연결 정보가 있어 함께 움직입니다. 그림 속 글은 두 번 눌러 직접 편집합니다. 완성 예시는 동일한 도형 배치에 메모를 채운 읽기 전용 그림이며 학생 기록에 복사하지 않습니다. 제공 도안만으로 제출 준비를 충족하지 않습니다. 기존 그림은 그대로 보존하며 ‘더 보기 → 기존 초안 보관하고 새 손그림 시작’은 먼저 현재 작업을 저장한 후 별도 수정본으로 새 도안을 만듭니다. 다운로드와 도형 라이브러리도 ‘더 보기’에 있습니다.

포트폴리오 결과물 팝업은 제출한 설계도 → 문제·제안·확인 방법 → 회고·코치 피드백 순서로 보여줍니다. 설계도는 편집 도구를 띄우지 않고 SVG 이미지로 표시하며 크게 보기, 그림 속 글 읽기, 그림·문서 다운로드를 지원합니다. 팝업 제목과 닫기는 고정하고 내용만 스크롤합니다. 오류 시 제출 설명을 유지하고 이미지 재시도를 제공합니다.

아직 제출하지 않은 시뮬레이션 자유 답변·질문·회고는 현재 화면의 입력입니다. 서버에서 저장 성공을 확인한 기록부터 재접속 시 복원됩니다.

페이지·카드 움직임은 앱의 단색 브랜드 디자인을 사용합니다. 모바일 메뉴, 키보드 조작과 움직임 줄이기를 지원합니다. 제공 이미지의 보존 범위는 [소개 페이지와 이미지 출처](landing-source.md)에 있습니다.


기존 /app/#map 링크는 프로필 기록 탭으로 연결합니다. 수동 확인 경로: 프로필 → 나의 진로 기록, 완료 → 회고 → 확인 → 홈의 다음 활동, 포트폴리오 → 결과물/수료 카드.
