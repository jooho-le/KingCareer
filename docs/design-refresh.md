# KingCareer 학생 앱 디자인 개편

경험지도에 적용한 직업별 크랩과 경험 수집 콘셉트를 학생 앱 전체로 확장했습니다. 색상은 주황 `#FF6A1F`, 보라 `#7C3AED`, 파랑 `#0967FF`와 단색 배경을 사용합니다.

## 화면별 변경

| 화면           | 변경 내용                                                                                                 |
| -------------- | --------------------------------------------------------------------------------------------------------- |
| 홈             | 크랩과 첫 경험 안내, 실제 수료·프로젝트·탐색 기록, 세 가지 바로가기, 다섯 직업 카드, 추천 이유, 최근 활동 |
| 공통 메뉴      | 선택 메뉴 강조, 크랩 안내, 헤더·버튼·탭·입력창·빈 상태의 모서리와 간격 통일                               |
| 직업 탐색·추천 | 직업별 크랩 카드와 추천 이미지, 이미지 영역에서도 상세·활동 진입, 저장 실패 안내                          |
| 직무체험       | 첫 출근 안내와 직업 선택, 현장 도구·조치 결과·과제 패널의 스타일 정리                                     |
| 미니 프로젝트  | 결과물 제작 안내, 직업별 설계 도안 미리보기, 작업실·초안 저장 패널 정리                                   |
| 포트폴리오     | 활동 카드·배지 컬렉션 정리, 직업별 크랩을 표시하는 수료 카드와 SVG 내보내기                               |
| 진단·계정      | 직업 선택 이미지, 객관식 선택 카드, 로그인·온보딩·프로필 폼 정리                                          |

주요 파일은 `src/pages/Basecamp.tsx`, `src/design-refresh.css`, `src/components.tsx`입니다. 기존 경험지도는 `src/pages/ExperienceMap.tsx`에서 유지합니다. 공개 소개 페이지는 별도 HTML이므로 학생 앱 테마가 적용되지 않습니다.

수료·제출 횟수와 추천은 기존 서버 응답을 사용합니다. 탐색 개수는 자기보고를 제외하고 `explored` 목표의 기록이 있는 직업 수입니다. 새 점수나 가상의 완료 기록을 추가하지 않았습니다.

## 사용자가 확인할 항목

소개 페이지에서 직업별 체험으로 직접 들어가는 비로그인 화면은 `src/fieldwork/CareerEntry.tsx`에서 제공합니다. 예전 연두색 출근 화면과 프로젝트의 기본 패널을 직업별 크랩·배경·업무 안내·로그인 버튼으로 교체했습니다. 로그인 버튼은 기존 인증 복귀 경로를 사용해 선택한 직업이나 프로젝트로 이어집니다. 소개 페이지의 3D 큐브와 체험 미리보기는 그대로 유지합니다.

추가 적용한 배경은 사용자가 제공한 `reference_image/KingCareerLLM_assets_v1/11_backgrounds/background01~04.png` 원본을 `public/brand/11_backgrounds`에 복사한 것입니다. 홈에는 01, 직무체험 목록에는 02, 프로젝트 목록에는 03, 경험지도 직업 커버에는 04를 사용합니다. `src/scene-backgrounds.css`에서 배경만 0.5~2px 흐리게 하고 글은 밝은 패널로 분리합니다. 입력창·3D 현장·설계 캔버스에는 배경을 덧씌우지 않습니다. 원본 이미지의 명암은 보존하며 CSS 그라데이션은 추가하지 않았습니다.

로그아웃은 마이페이지의 프로필 카드 안에 있습니다. 상단 프로필 아이콘이나 사이드바의 계정을 누르면 찾을 수 있습니다. `/auth/logout` 성공 후 개인 상태를 비우고 로그인으로 이동합니다. 이미 만료된 세션(401)도 로그인으로 이동하며, 그 외 요청 실패는 재시도를 제공합니다. 로그아웃 처리 중 본문의 추가 입력을 막습니다. 프로젝트에서 마이페이지로 이동할 때는 기존 초안 저장 가드가 실행됩니다.

프로젝트 본문은 16px, 도구·저장 버튼은 15px로 조정했습니다. 안내·저장 바·설계 도구를 독립된 영역으로 배치하고 도형 라이브러리는 펼쳐보기로 정리했습니다. 앱 메뉴는 `.app-sidebar`로 이름을 분리해 Excalidraw의 `.sidebar`와 충돌하지 않게 했으며, 공통 버튼·입력창 스타일에서 Excalidraw 내부를 제외했습니다. 기존 브라우저 테스트가 앱 메뉴를 `.sidebar`로 찾는다면 `.app-sidebar` 또는 내비게이션 역할 기준으로 변경해야 합니다.

개발 용어는 초안·체험·활동 기록 중심으로 바꾸고 실제 수신 알림이 없는 표시등을 제거했습니다. AI 답변·미리 작성된 학습 안내·평가하지 않은 활동 기록은 계속 구분합니다.

- 홈 → 직업 선택 → 체험 → 수료 카드 → 프로젝트 → 포트폴리오 이동.
- 비로그인 상태의 소개 페이지 → 바로 체험하기 또는 각 직업의 출근 버튼 → 직업 안내 → 로그인·가입 → 선택한 현장. 프로젝트 직접 링크도 같은 방식으로 확인합니다.
- 각 직업 카드와 수료 카드 다운로드의 크랩 이미지 일치.
- 모바일 메뉴, 카드·입력창·설계 작업실의 폭과 스크롤.
- 키보드로 카드 열기·직업 저장·탭 선택, 시스템 움직임 줄이기 적용.
- 새 계정의 빈 상태, 저장 실패 안내, 재접속 후 실제 활동 개수.
- 프로필 아이콘 → 마이페이지 → 로그아웃, 실패 시 로그인 유지와 재시도.
- 프로젝트 안내·저장 도구의 줄바꿈, 도형 라이브러리 펼치기·가져오기, 편집기 내부 텍스트 입력과 모바일 도구 배치.
- 네 배경의 모바일 자르기와 글 가독성, 움직임 줄이기 적용 시 배경 확대 효과 중지.

요청에 따라 기능·브라우저 테스트는 작성하거나 실행하지 않았습니다.
