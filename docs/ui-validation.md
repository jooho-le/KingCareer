# 현장 중심 직무체험 — 2026-09-13

- `simulation-review-ui.spec.ts` 5개와 `activity-help-usability.spec.ts` 2개가 최종 묶음 실행에서 모두 통과했다. 네 화면 크기의 배치, 자료 조사·조치 결과·회고, 화면 설정 복원, 실패·재시도·중복 조사 방지, 키보드 포커스, 크기 변경 후 카드·선택 유지, 수료 카드 다운로드와 정확한 활동 연결을 확인했다.
