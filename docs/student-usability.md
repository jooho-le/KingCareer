# 학생 사용 흐름 개선

2026-09-13 사용자 관점 리뷰를 반영했습니다. 서비스 소개 페이지의 원본 구성은 유지합니다.

## 시작과 이동

- 주 메뉴는 **홈 / 직무체험 / 미니 프로젝트 / 포트폴리오**입니다. 프로필에서 진로 기록과 설정을 엽니다.
- 홈은 진행 중 활동, 회고에서 고른 다음 활동, 추천 순서로 대표 행동 하나를 보여줍니다. 최근 완성한 결과를 바로 아래에서 열 수 있습니다.
- 전체 직업 목록은 펼쳐 볼 수 있고, 무엇부터 고를지 모를 때 경험 확인으로 연결합니다.
- 직무체험 목록 안에서 직업·분야·전공 검색, 관심 분야 선택, 저장한 직업 필터를 사용합니다. 하는 일·관련 전공·출처는 필요할 때 펼칩니다.
- 기존 직업 탐색·진단·추천 URL은 유지합니다. 선택한 직업은 로그인 후에도 이어집니다.

## 직무체험

현재 할 일, 현장 자료, 선택, 결과 순으로 읽습니다. 모바일에서는 조사를 마친 뒤 자료가 접히고 다시 열 수 있습니다. 데스크톱은 진행 중 3D 현장을 유지합니다. 단계가 바뀌면 현재 할 일로 키보드 포커스를 옮기며, 작업일지는 펼쳐서 읽습니다.

## 그림 안에서 완성하는 프로젝트

- 새 초안과 기존 결과물 모두 **그림 편집기**에서 엽니다. 별도 단계 카드와 문장 빈칸 폼은 제거했습니다.
- 새 프로젝트는 직업에 맞는 손그림 흐름도로 시작합니다. 그림 속 글은 두 번 눌러 직접 고칩니다. 별도의 빈칸 탐색 버튼이나 자동 선택·확대 기능은 없습니다.
- ‘완성 그림 예시’는 읽기 전용이며 학생 작업을 변경하지 않습니다. 작은 화면에서는 예시를 확대해 살펴볼 수 있습니다.
- 빈 캔버스에는 ‘손그림 흐름도 넣기’, 그림이 있으면 ‘그림 전체 보기’를 표시합니다. 새 도안으로 바꿀 때는 기존 초안을 저장해 수정 이력에 보관합니다.
- 미완성 그림도 저장·복원합니다. 가이드만 넣었거나 예약 빈칸이 남아 있으면 제출할 수 없습니다. 완성 여부 확인은 정답 평가와 별개입니다. 기존 세 설명과 관심도 선택은 유지합니다.
- 그림은 페이지 스크롤과 분리하고 설명 패널만 따로 스크롤합니다. SVG·PNG 다운로드와 라이브러리는 ‘더 보기’에 모아 그림 공간을 확보했습니다.

## 도움말과 접근성

- 도움말은 계정과 화면 종류별 최초 한 번 자동 표시합니다. 직업을 바꾸거나 새로고침해도 반복되지 않습니다. 같은 브라우저의 저장소를 사용합니다.
- 화면 안내 버튼과 프로필 설정에서 다시 볼 수 있습니다. 기존 ‘다시 보지 않기’ 설정도 유지합니다. 설정을 해제해도 이미 본 화면의 최초 방문 기록을 지우지는 않습니다.
- 프로젝트 안내는 과제 → 그림 가이드 → 설명 → 제출 순으로 실제 패널을 엽니다. 닫으면 원래 보고 있던 패널로 돌아갑니다.
- 숨긴 모바일 메뉴는 키보드 포커스를 받지 않습니다. 현재 메뉴 표시, 본문 건너뛰기, 도움말 포커스 가두기와 Escape 닫기를 유지합니다.
- 주요 조작 글자와 터치 영역을 키우고 주황색 제출 버튼의 글자 대비를 높였습니다. 기존 움직임 줄이기 설정을 유지합니다.

## 학생에게 어울리는 시각 표현

단순화 이후 학생에게 너무 차분해 보인다는 피드백을 반영했습니다. 네 가지 주 메뉴와 활동 순서를 유지하면서 홈·활동 목록·포트폴리오의 주황·보라·파랑 면적과 캐릭터를 키웠습니다. CSS 그라데이션을 추가하지 않았습니다.

- 홈: 파랑 캐릭터 무대, 주황 안내 라벨, 보라 제목, 입체 버튼과 수료 티켓 형태의 최근 결과. 모바일·재방문에도 원본 크랩을 표시합니다.
- 직무체험: 파랑 입장 안내와 직업별 캐릭터 장면. 검색과 상세 설명은 같은 위치에서 이용합니다.
- 프로젝트: 주황 작업실 안내와 직업별 색상 카드, 결과물을 예상할 수 있는 단계 미리보기.
- 포트폴리오: 보라 컬렉션 표지와 실제 설계도의 색상 프레임. 표시하는 체험·결과물 개수는 저장된 활동에서 계산합니다.
- 캐릭터 등장과 카드 진입은 한 번 재생하고, 호버·누르기에 반응합니다. 움직임 줄이기 환경에서는 장식 애니메이션을 끕니다. 글을 읽고 입력하는 작업실의 배치는 유지합니다.

## 확인 범위

`npm.cmd run test:e2e`로 현행 브라우저 시나리오를 확인합니다. UI 검사는 모의 API를, 실제 저장 검사는 임시 로컬 계정을 사용합니다. 모델 호출은 대체합니다. 그림 속 빈칸 편집·예시·초안 보존은 `tests/project-drawing-guide.spec.ts`, 제출 준비 검사는 `tests/test_project_readiness.py`, 기존 카드 결과물의 서버 저장 호환성은 `tests/backend_review_test.py`에서 확인합니다.

실제 검사 결과는 [UI 검증 기록](ui-validation.md)을 참고하세요. 실제 학생을 대상으로 한 사용성 조사, 모든 보조공학 기기의 접근성 인증, Gemini의 답변 품질 검증을 의미하지 않습니다.
