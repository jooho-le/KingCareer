# 활동 화면 디자인 정리

작업 도구의 시각적 참고는 [Tinkercad 공식 가이드](https://images.tinkercad.com/jl5ii4oqrdmc/1eTWASZYKjnMX9u5ioLh8Y/bb2dfb24cfc4bd66adc485baaecedf97/Tinkercad_Getting_Started_Guide_ISTE.pdf), 활동 목록은 [Forage](https://www.theforage.com/simulations)를 참고 대상으로 삼았습니다. 서비스 이미지나 UI를 복사하지 않고 KingCareer 원본 캐릭터와 단색 브랜드를 유지합니다.

- 카드: 이미지·제목·메타 정보의 위계, 일정한 모서리와 테두리, 간결한 그림자.
- 작업실: 흰색 도구 영역, 파란색 도안 버튼, 보라색 패널 탭·코치, 주황색 제출.
- 도움말: 사용자가 제공한 예시처럼 전체 화면을 어둡게 덮고 SVG 마스크로 실제 대상만 밝게 표시합니다. 곡선 화살표와 설명, 다음·이전·닫기·다시 보지 않기를 제공합니다. 화면 레이아웃에 설명 요소를 삽입하지 않습니다.
- 위치: 대상 요소의 실제 좌표를 읽고 크기 변경·스크롤 시 다시 계산합니다. 작업실 저장 상태·제출·도안·패널 탭을 순서대로 안내합니다.

수동 확인: 모바일·데스크톱 강조 위치와 문구 겹침, 창 크기 변경, Escape·Tab, 닫기 후 캔버스 조작·목록 스크롤, 계정별 다시 보지 않기, 설정에서 재실행. 화면 테스트와 AI 호출은 실행하지 않았습니다.
