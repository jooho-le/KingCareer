# KingCareer Experience Graph / Gap Engine

웹 프레임워크와 데이터베이스 없이 NetworkX만 사용하는 Python 모듈입니다. `ExperienceGraph(careers, sources)`에 직업 카탈로그와 출처 스냅샷을 전달하고 `report(career_id, evidence)`로 경험목표 기록 충족률을 계산합니다. `recommend(reports, profile_interests)`는 부족한 목표에서 활동으로 이어지는 경로와 추천 이유를 반환합니다.

독립 설치: `python -m pip install ./backend/experience_graph`. 이후 `from kingcareer_experience_graph import ExperienceGraph`로 사용합니다. 소스 코드의 MIT 라이선스는 이 패키지에 적용되며 ESCO·O*NET 데이터의 재사용 조건을 변경하지 않습니다. 직업 카탈로그와 출처 데이터는 호출자가 전달합니다.

그래프는 서비스 직업, ESCO 직업·필수 역량, O*NET 업무, KingCareer 교육용 목표, 활동으로 구성합니다. 공식 직업과 서비스 직업의 연결 및 역량·업무에서 교육 목표로의 연결은 `editorial_crosswalk`, `educational_context` 관계로 표시합니다. 공식 직업 분류가 학생의 능력을 평가한다고 주장하지 않습니다.

각 차원의 충족률은 기록이 있는 고유 목표 수 / 그 차원의 목표 수입니다. 동일 목표에 100번 응답해도 한 번만 충족합니다. `unknown`은 목표의 확인 기록이 하나도 없는 경우입니다. 점수는 교육용 기록 충족률이며 직무 능력·성취·적성의 검증 점수가 아닙니다.

`mappings.py`에는 직업별로 실제 확인한 O*NET 업무 3개와 ESCO 역량 2개의 ID·한국어 편집명을 담습니다. 교육 목표에 관련 있는 출처만 연결합니다. 학생별 그래프 사본에 목표별 활동과 실제 근거 노드를 추가하고 NetworkX의 도달 가능한 근거를 세어 계산합니다. 추천의 `path`는 직업 → 공식 출처 → 선택한 업무·역량 → 교육 목표 → 활동 경로를 보여주고, `sourcePath`에는 감사용 원본 노드 ID를 담습니다.

| 차원 | 목표 | 인정 근거 |
| --- | --- | --- |
| 직업 인식 | 직업 소개 탐색 | 서버에 저장된 탐색 이벤트 |
| 직무 이해 | 3개 상황 응답 + 회고 | 선택/자유 답변의 존재, 회고 제출 |
| 활동 경험 | 시뮬레이션 완료 + 프로젝트 제출 | 서버에서 확인한 완료 조건 |
| 역량 이해 | 프로젝트 2·3단계 작성 | 제출물의 존재 |
| 학과 이해 | 관련 전공 조사 확인 | 이번 버전에는 검증 경로 없음 |
| 현직자 교류 | 실제 현직자 교류 확인 | 이번 버전에는 검증 경로 없음 |

진단은 `self_report`로 별도 보존하고 충족률 계산에서 제외합니다. 실제 외부 교류와 가상의 직무체험을 구분합니다. 제출물 내용은 AI 미연결 상태에서 평가하지 않습니다. 현 버전에서 `major_verified`, `mentor_verified` 목표를 클라이언트가 직접 제출할 API는 없습니다.

`ExperienceEvidence` 입력은 신뢰 경계 안에서 검증된 서버 이벤트여야 합니다. 클라이언트가 보낸 임의 목표 ID·배우·점수는 입력으로 사용하지 않습니다. `verified`는 서버가 해당 기록의 존재를 확인했다는 뜻이며 내용의 정답·실무 능력을 검증했다는 뜻이 아닙니다.
